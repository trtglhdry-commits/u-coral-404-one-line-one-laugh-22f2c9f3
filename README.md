## The line

> I told my GPS I wanted the scenic route; it drove past my ex's house and called it character development.

## How it works

`main.ts` (Node 22, stdlib only) writes that one fixed line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic:
no input, no clock, no randomness, no network — the same line every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
